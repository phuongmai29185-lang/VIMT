# PhotoCard Studio

Web tạo ảnh thẻ từ ảnh có sẵn, chạy hoàn toàn trên trình duyệt.

## Tính năng
- Chọn ảnh JPG/PNG/WEBP.
- Căn chỉnh X/Y và zoom.
- Kích thước 2x3, 3x4, 4x6 cm.
- Chọn màu nền.
- Tải ảnh JPG.
- Tạo trang A4 nhiều ảnh để in.
- Không upload ảnh lên máy chủ.

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub.
2. Upload 4 file trong thư mục này.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**.
5. Chọn branch `main` và thư mục `/ (root)`.
6. Lưu lại và mở địa chỉ GitHub Pages GitHub cung cấp.

## Ghi chú
Phiên bản hiện tại căn ảnh theo vùng trung tâm. Chưa có nhận diện khuôn mặt tự động.
